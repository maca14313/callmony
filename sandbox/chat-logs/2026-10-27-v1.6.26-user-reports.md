## Decode & fix map

| # | Report | Root cause | Fix |
|---|--------|-----------|-----|
| 1 | Recents card shows the NUMBER for a moment at open | `hydrate()` published the cached CALL LOG at boot but NOT the cached CONTACT BOOK, so cards matched against an empty book for the seconds the real fetch takes (it only starts at +4 s in the boot chain) | `Store.hydrate` loads `contacts-cache-v2.json` and publishes it in the SAME batched main hop — first frame already shows names; the fresh fetch replaces it silently later |
| 2 | Long-press the call icon → number options | The call button was a plain `clickable` dialing the first stored number | `combinedClickable` onLongClick → the "Choose a number" sheet with the contact's DISTINCT numbers (rendered at screen level — a BottomSheet inside a LazyColumn item collapses its scrim). Cards also dial the FAVOURITE number first now (`primaryPhone()`) |
| 3 | Bottom nav ALWAYS visible, nothing covered/overlapping | Every overlay rendered in a full-screen Box AFTER the shell Column — hiding the nav under contact detail / search / settings / calculator / keypad / sheets | OverlayHost, keypad sheet, More sheet, alarm dialog, toaster, confirm + host sheets all compose INSIDE the content area (between header and nav). Content Box ends where the nav begins → nothing can render under it either. Redundant system-bar paddings stripped from Sheet/BottomSheet/Calculator/KeypadSheet/ContactPicker/Search; toast offset recalibrated (96→10dp). Splash/lock/onboarding stay full-screen by design |
| 4 | Calculator 55% keypad / 45% display, no display border, colourful keys | Old layout: fixed-height display card with a hairline border, keypad took the remainder; keys were grey cards | Body splits EXACTLY weight(45f)/weight(55f); display borderless (flat card tone, 40sp ExtraBold main, 24sp preview above); operators brand green, AC red, ⌫ amber, %/± blue, = solid ink, digits+'.' cycle a soft 5-hue tint (teal/blue/violet/amber/rose) |
| 5a | Credit tab doesn't show the contacts that have them | The kind row filtered only ENTRIES; browse-mode contacts were unfiltered | New `contactsWithKind` set: recordIDs with ≥1 non-deleted entry of the active kind inside the active date window — matchedContacts (query AND browse) filter through it |
| 5b | Date tab needs a custom date to filter ANY date | Only Today/7d/30d/Overdue windows existed | Custom chip → from/to sheet with two native Material-calendar PickerFields (open ends allowed) → `dateFilter="custom"` compares entry.date strings; range applies to entries AND contact matching |
| 6 | Most secure app — no data loss even after reinstall/update | Updates were already safe (same signing key + lenient JSON loader + mirrored prefs commits); REINSTALL wiped app data with no recovery path | Three layers: (a) explicit Auto Backup rules for both engines (fullBackupContent + dataExtractionRules: sharedpref/file/database/external ride cloud backup + device transfer); (b) Export backup shares a REAL .json FILE via FileProvider (cacheDir/backups + file_paths.xml) — "Save to Files/Drive/Downloads" saves a file that SURVIVES an uninstall; (c) Restore-from-file via a new transparent FilePickActivity hosting the SAF picker, streaming the file text back on main and restoring (merge + confirm) |
| 7a | First icons row scrollable; remove ledger icon; FIXED More at the end → grid with socials + first-row icons + add-social + edit; socials get LABELS | The 12-tile 6×2 grid had everything crammed in two rows; the More sheet was a scrolling strip + rows | First row = side-scrolling Call/SMS/WhatsApp/Telegram/Email strip + a FIXED brand-soft More tile at the end. More sheet = GRID (4 per row, equal widths): quick actions, saved socials WITH THEIR LABELS, per-number WhatsApp/Telegram, ＋ add-social, ✎ edit — then the add-to rows, general actions, Block/Unblock (nothing lost). `SocialLink.label: String = ""` (backward compatible), Add-social sheet asks for it ("e.g. Work, Family"); Info tab shows it |
| 7b | Remove the second icon row; tabs WITH icons; bank DIFFERENT colour | The grid's second row duplicated the segmented tabs' destinations | Second row gone; `Segmented` gained optional `iconOf` + `tintOf` params (positioned BEFORE onChange so all existing trailing-lambda call sites compile unchanged); tabs carry book/lists/notes/bank/bell/info glyphs, the BANK tab in its own blue (active fill + inactive text) |
| 7c | "+ Expense" and "More" different from their friends | Secondary row used generic ghost Chips under the primary row's custom pills | ONE `ActionPill` design shared by the primary row (＋Credit/＋Debit/＋Income) and the secondary row (＋Expense/＋Debit, New group, Share statement) |
| 8 | Favourite icon in the choose-a-number | The picker had no per-row favourite control | `NumberPickerSheet` gained `recordID` + `favouriteNumber`; every row carries a star (filled amber when active) that calls `AppStore.setPrimaryPhone` — the number the app dials first everywhere |
