## Decode + fix map

| # | Report | Root cause | Fix |
|---|--------|-----------|-----|
| 1 | Opens slower now | v1.6.26 put the cached CONTACT BOOK (the app's largest JSON blob) on the boot path AFTER the store load and the call-log cache — first frame waited the SUM of three big reads | `Store.hydrate` runs all four loads (store / calls / contacts / PIN) CONCURRENTLY — first frame waits the MAX; same single batched main hop, names still land on frame one |
| 2 | Keypad pushed to bottom under the navbar when contacts show | The live-match list was `heightIn(max=250)`; panel total exceeded the content area and a bottom-anchored column clips its TAIL (bottom keys + call button under the nav) | The list is now `weight(1f, fill=false)` — it takes only the space LEFT above the fixed keypad and scrolls inside it |
| 3 | Picker needs favourite star (set/UNSET) before the call icon + copy (long-press + icon); card dials favourite first everywhere | The v1.6.26 recents picker had only label + number + call; favourite-first dialing missed several surfaces (keypad matches, speed dial, call row sheet) | Every picker row: [label][number][copy][star][call] + long-press copy; NEW `Store.clearPrimaryPhone` (tap the filled star to unset); both pickers share the design; primaryPhone() now backs cards, call row sheet, keypad matches, keypad speed dial, speed-dial grid, search hits |
