# 2026-11-22 (b) — v1.6.54 THE ROUND 2 CORRECTION LIST

## The user's report (verbatim decode)

After the v1.6.53 Light Glass spec-correction round, the user reviewed the
screenshots and sent ROUND 2 — an exact 10-point correction list with the
screenshots as evidence, plus one addendum in their own words:
**"i dont want the blue colour spilling in to things, the bg should be only
white"**. The reported misses:

1. Sheets still see-through (Add entry / Keypad / More — the page text
   behind readable: "Credit Nov 7…", "People", "Hamzaa Tepi").
2. Wrong nav item highlighted (Calculator screen lit Recents; More sheet
   lit General + More together; Settings lit General).
3. Text cut off everywhere ("Calcul…", "Calculat…", "WhatsA…", "They owe
   y…", "You owe th…", "503886.2…", "Income 505272.…"; the hero
   "505272.8M Br" nearly touched the screen edge).
4. Chip rows clipped with no scroll hint ("Re", "Accounts", "KES", "SA").
5. Avatars washed out (white letters on random pastel colors, not brand).
6. Keypad missing its number display + suggestions; dull grey call button.
7. Bottom system bar a plain white strip under the nav (gradient didn't
   reach the screen edge).
8. Header band changing between screens (darker blue band with a hard
   edge on inner screens vs blending on Home).
9. Calculator digit keys alternating white/blue in a checkerboard.
10. (Teal only in the logo mark — the standing rule.)

## Why it happened (the user's own diagnosis, accepted)

The broad look was followed but the exact rules were fudged ("fully
opaque" shipped as 0.96 alpha; "never truncate" shipped as ellipsis;
"only one selected" shipped as tab-only selection). Each screen was
built separately, so the small misses differed per screen. The fix
strategy the user prescribed: apply every correction through SHARED
COMPONENTS, not per-screen patches — which is exactly how this round was
executed.

## The fixes (all in shared components)

1. SHEETS/MENUS/DIALOGS — `BottomSheet`, `KeypadSheet` panel,
   `ConfirmHost` dialog, `GlassPanel`, `GlassCard`, `Card`, More tiles,
   the toast: every surface moved from `White.copy(alpha=…)` to
   **`Color.White` alpha 1.0** (dark: solid navy). The scrim is the
   spec's **Ink @40%** (`Theme.LIGHT.scrim = 0x660F1B2D`; was 35%).
   Sheets already anchor above the always-visible nav (v1.6.26
   architecture) so nothing hides under the bottom bar.
2. BOTTOM NAV — `selectedTab` is ROUTE-derived in `BottomNav`:
   Calculator overlay → "calculator"; More sheet open / reminders /
   trash → "more"; else the tab. `NavSlot` takes `selected` explicitly
   (no more reading `UiStore.tab` alone). Exactly one white@20% pill,
   ever. Nav label "Calc" (EN) / "حاسبة" (AR) — one line, no ellipsis,
   fits at 360dp; the Calculator screen TITLE keeps the full word via
   the new `calc.titleFull` key (all 5 languages).
3. NO TRUNCATION — shared kit: `Btn` labels `maxLines=2` + softWrap +
   textAlign Center (never ellipsis); non-compact `Chip` labels 2 lines;
   `Pill` labels 2 lines; sheet/app-bar titles 2 lines
   (`TextOverflow.Visible`); `MoreTile` labels 2 lines; the ledger card
   title 2 lines; the call-card owe pill label 2 lines. MONEY: new
   `AutoFitText` (measure-and-shrink) powers `Money` between
   **14sp and 44sp, one line, never ellipsized**; the General hero keeps
   its HeroNumeral ladder. App bar: the Calculator header's four action
   controls collapsed to ONE labelled History pill + a three-dot
   OVERFLOW menu (Σ · Paste · Copy) so the title renders in full.
4. CHIP ROWS — `ScrollRow` rewritten with the exact recipe:
   `graphicsLayer(compositingStrategy = Offscreen)` +
   `drawWithContent` gradient + **`BlendMode.DstIn`** — a real alpha
   mask (chips genuinely dissolve at the edge; the old painted-veil
   fade that covered chip text is gone), **24dp** fade band per edge
   while content hides beyond it, plus **16dp content padding** so the
   first/last chip are never cut. `Segmented` tabs now ride ScrollRow.
   The two Recents owe tabs moved into a scrolling fade strip (full
   labels, never "They owe y…").
5. AVATARS — `Avatar` is the **BrandLight→BrandDark gradient** with
   white 600-weight initials for EVERY contact (contrast ≥ 4.5:1 on both
   stops). The deterministic pastel `avatarColors` palette is no longer
   referenced by any UI (the function remains for data compat).
6. KEYPAD — the typed number renders ABOVE the keys: **ExtraLight
   (non-bold) 48sp in Brand** (stepping down 40/32/26 only for very
   long numbers), still the real editable field (native copy/cut/paste
   menu, IME suppressed). **Up to 2 suggested contacts** under it (was
   an unbounded 60-row list that buried the keys). The call button was
   already the Brand gradient when a number is typed (grey only empty)
   — kept and re-verified.
7. EDGE-TO-EDGE + THE WHITE BACKGROUND — `enableEdgeToEdge()` stands;
   system bars stay transparent with insets as padding only. The screen
   background is **PURE WHITE everywhere** (round 2's addendum): the
   #EAF3FF→#FFF3EE gradient and BOTH radial glows are deleted; brand
   blue lives only in components (nav bar, buttons, avatars, keypad,
   chips, focus states). The dark theme is a flat deep-navy solid. With
   the white page, the area behind the gesture bar is white-on-white —
   no strip, no seam, gradient-to-edge question dissolved.
8. APP BAR — identical everywhere by construction: the header renders
   transparent over the SAME pure-white page on every screen (the
   per-overlay gradient canvases that produced the "darker blue band
   with a hard edge" are gone); the secondary header's back button is
   opaque white.
9. CALCULATOR — uniform tiles: ALL digits + ⌫ + ± the SAME white tile
   (ink text); operators Brand50 with Brand text; **"=" the Brand
   gradient** (linear BrandLight→BrandDark, white text); AC the Danger
   tint. The `numTints` index-cycling checkerboard is deleted.
10. TEAL — tree sweep: zero teal outside the logo mark (comment-only
    references remain).
