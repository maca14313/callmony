## Implementation notes

- **GlassTokensSpec** (Glass.kt): the canvas stops, glow count, glow
  positions and alpha caps as an exposed object — the single place the
  background grammar lives, and what the new test pins.
- **DIALER_FAB_PULSE_CYCLES = 3** (CallmonyApp.kt): bounded pulse, same
  discipline as the v1.6.51 AlarmDialog bounding. The zero-infinite-
  animations rule is NOT broken: the ring runs ~4.8s once per process,
  then the FAB is a static gradient circle.
- **Platform.ui.reduceMotion**: expect/actual addition. Android reads
  `Settings.Global.ANIMATOR_DURATION_SCALE == 0`; the default interface
  impl returns false (iOS/desktop). The DialerFab consults it before
  starting the pulse.
- **HeroNumeral**: BoxWithConstraints + rememberTextMeasurer; the ladder
  steps 48→44→40→36→32→28→24→20sp and picks the first size whose
  measured single-line width fits; the Text is maxLines=1 + softWrap=false
  (single line by construction). Used by the General net (tag
  heroNumeral:generalNet; red when negative).
- **Nav labels**: NavSlot renders icon + 10sp label inside the existing
  64dp bar; the active pill is RoundedCornerShape(999.dp) white@20%. The
  overdue badge rides the More icon as before. The 71dp total is kept
  (64 bar + 7 bottom inset) — pinned by the new geometry test.
- **Hex sweep**: RecentsScreen (swipe actions, star, permission border,
  balance pills), ContactDetail (stars, WhatsApp tiles, balance pill),
  ContactEditor (default-number star), Calculator (5-hue palette →
  Brand/Brand50), EntryEdit calc keys + TEXTMODE_COLOR → BrandDark,
  ListsReminders/NotesBank sections (swipe hues), MiscOverlays (offline
  pill already token-green; dialog 24→28dp). Kit's dark-mode twin hexes
  and the toast's ink pill stay (deliberate, theme-aware).
- **480dp caps**: RecentsScreen, GeneralScreen, RemindersScreen,
  TrashScreen roots get `.widthIn(max = 480.dp)` + centered column.
