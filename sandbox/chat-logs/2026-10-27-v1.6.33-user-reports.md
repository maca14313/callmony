## Interpretation & resolution

This is the v1.6.30 feature list re-sent — the user never saw any of those
features because every v1.6.30/31 build closed on open. The stable v1.6.32
base (v1.6.29 launch path + splash + the focus ring + the history-button
anchor) is now the foundation, and the features are re-applied as audited
ports. The splash STAYS.

1. **Post-call refresh** — REBUILT launch-safe instead of copied: observer
   arms on the first onResume (never in the onCreate/setContent window),
   rides a dedicated background HandlerThread (provider bursts never touch
   the main thread), debounced 1.2s guarded refresh gated on hydrate,
   unregisters in onDestroy. New PostCallRefreshTest locks: boot completes,
   observer armed, provider write flows the whole chain
   (recents.observerRefresh BootTrace mark).
2. **Recents tabs** — ported: oweTab is its own toggleable state, an active
   owe tab reveals the All/Missed/Incoming/Outgoing/Favorites filter row
   (both filters compose), and the Recents nav button bumps
   UiStore.recentsResetTick → the view snaps to nothing-clicked.
3. **Calculator copy/paste** — ported: long-press copies, PASTE chip beside
   the copy chip, sanitizePastedExpr cleans the text (5-case V1630Test).
4. **Detail-page icon in the long-press sheet** — ported: account-circle
   icon after the name (saved contacts) opens the contact-detail page.
5. **Full number in the strip** — ported: tiles grow to the whole
   pretty-printed number (was 196dp + ellipsis).
6. **Ledger quick item (label + price)** — ALREADY THERE: this is exactly
   v1.6.29's quick item (the label+price row exists only inside the
   credit/debit/income/expense kind tabs of the new-entry sheet; one tap
   creates the priced entry with the tab's kind). It stayed through the
   rollback; confirmed to the user rather than re-implemented.

Plus the lighter call cards riding the ported Recents screen (originally
asked in the same v1.6.30 batch: "the call cards are little bit havey").

Launch-path discipline: everything is a pure UI port from the audited
v1.6.30 diff except the observer (new code, designed launch-safe); the
splash path, the shell, hydrate and the v1.6.31 crash-guard experiment
remain exactly as v1.6.32 shipped them. DEX-verified on the shipped APK:
SplashPane PRESENT, storeCrashGuard ABSENT, new feature symbols PRESENT.
