## The decode

Items 1–17 are EXACTLY the v1.6.17 + v1.6.18 report lists — the user
re-sent them because the rollback removed those fixes along with everything
else. The freeze that made v1.6.17+ "crash" was root-caused during the
v1.6.19–23 rounds: (a) the autolock touch observer's gesture block returned
without awaiting any pointer event → 100% CPU busy-spin on the main thread
from the first touch until the 5 s input ANR (v1.6.22); (b) an invisible
infinite CircularProgressIndicator under the opaque onboarding sheet
(v1.6.19); (c) main-thread disk IO / stacked commits (v1.6.18's queue fixed
this); (d) background threads publishing Compose state (v1.6.21); (e) a
double whole-book contacts read on the permission grant (v1.6.23).

## What shipped (v1.6.24, versionCode 35)

1. Restored the v1.6.17/18 feature tree (git checkout 550ffb8 --
   composeApp iosApp) — every item 1–17 came back with it, including the
   rebuilt contact detail, the advanced search, the attachments system,
   block contacts, the bottom-anchored host sheets, and the working
   reminder engine (any interval + ALARM).
2. Kept ALL v1.6.19–23 stability fixes that came with that tree (gated
   spinner, Persist IO queue, single-batch publishing, fixed gesture
   observer, Mutex-gated contacts fetch) — this is what makes it "not
   crash like before".
3. REMOVED the v1.6.20–23 diagnostics suite entirely: Diag.kt (watchdog,
   BlockageDetector, reports, storage), DiagAndroid.kt (AnrWatchdog, crash
   firewall), DiagActivity.kt (:diag process screen), DiagnosticsOverlay,
   DiagStorage.ios.kt, DiagTest.kt, the manifest entry, the diag theme,
   the Settings row, every hook. Survived as a 15-line BootTrace phase
   marker so the boot harnesses (BootDiagTest / UpgradeBootDiagTest) keep
   guarding the freeze-on-open class.
4. UI depth polish: soft shadows on Card (both pressable and plain), on
   primary/danger buttons, on the bottom Sheet surface and the KeypadSheet
   panel (10 dp) — the "flat / bulky" complaint.
5. Version 1.6.24 / versionCode 35 (must exceed the rollback's 34).
