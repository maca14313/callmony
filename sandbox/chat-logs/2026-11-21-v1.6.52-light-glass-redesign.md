# 2026-11-21 — v1.6.52: The Light Glass redesign

## The request

The user supplied a complete "Light Glass" design spec and asked it applied
to every screen and component: bright white backgrounds with frosted-glass
cards over soft colored glows, one strong brand color (#1F7AEC), generous
rounding, large light-weight numerals, brand-tinted shadows; Material 3
re-themed (never default purple); the Lexend typeface; stroke-style icons
(Lucide-like, 1.8dp, round caps); gradient initials avatars; transparent
underline text fields; a floating solid-Brand bottom bar with a center FAB;
subtle 120-200ms motion with press-scale; 100% Compose Multiplatform in
commonMain. "Check the github and at the end commit to the github, even the
.tar build file and I want Releases."

## What shipped (v1.6.52, vc63)

**GitHub reconciled first** — the sandbox was 27 commits behind (v1.6.25 →
v1.6.51); ff-only merge to v1.6.51 before any work. The ANR/prefix/
data-loss batch turned out to be already shipped in v1.6.51 on the remote,
so this round is purely the Light Glass reskin.

**Design tokens (theme/Theme.kt)** — `AppColors` (Brand #1F7AEC, BrandLight
#3B94FF, BrandDark #1565D8, Brand50 #EEF5FF, Accent #FF6B4A, Ink #0F1B2D,
Muted #64748B, Line = brand@10%, Success/Danger/Warning) and `AppShapes`
(Card 24dp, Sheet 36dp, Tile 12dp, Pill 50%) exactly per spec. The legacy
`ThemeColors` API (every screen reads colors through `C()`) is retained and
re-pointed: LIGHT is now the Light Glass palette (near-white canvas, brand
hairlines), DARK is a matching deep-navy glass cut, so the existing theme
switch keeps working. One palette change re-skinned the whole app.

**Lexend typeface (composeResources/font/)** — the official Google Fonts
variable font instanced at 200/300/400/500/600/700 with fonttools
(scripts/lexend_instance.py), six ~78KB statics in commonMain. 200/300 are
the hero-numeral cuts, 400 body, 500 labels, 600 titles per spec.

**AppTheme (theme/AppTheme.kt)** — the app was bare Compose (no
MaterialTheme) since v1.0. The new wrapper provides the re-themed M3
lightColorScheme (primary=Brand, primaryContainer=Brand50, outline=Line,
tertiary=Accent — never default purple) plus a Lexend Typography, and sets
the ambient `LocalTextStyle` to **family-only** — the family flows to every
bare Text() without a call-site edit, but fontSize/lineHeight NEVER ride
the ambient style (the app's pixel-pinned surfaces — the canvas's 11-stop
pixel ladder, the date-beside-total contract, the prefix slot geometry —
own their metrics; the first compile attempt let M3 lineHeights leak and
the v1.6.49 date/total pin caught it immediately. Metrics contract
documented in the file).

**Lucide stroke icons (ui/icons/LucideIcons.kt)** — the app's entire used
icon surface (51 distinct names — enumerated from the tree) rebuilt from
lucide-static 1.77.0 (ISC) as stroke ImageVectors: 24x24, 1.8dp stroke,
round caps/joins. `MdiIcon()` resolves the Lucide cut first and falls back
to the legacy filled MDI vector, so every screen switched to stroke-style
icons with ZERO call-site edits. Generated by scripts/gen_lucide_icons.py
(rect/circle/line children converted to path data; circle subpaths stay
OPEN so strokes don't double).

**Glass surface kit (ui/components/Glass.kt)** — `glassCanvas()` (the
#EAF3FF→#FFFFFF→#FFF3EE diagonal gradient + 2-3 large radial glows in
brand/accent/teal, drawn with drawBehind — NO Modifier.blur, identical on
Android/iOS/desktop; a navy dark-mode twin), `GlassCard` (white @78%, 1dp
brand@10% hairline, 24dp radius, brand-tinted 12-20dp shadow), `GlassPanel`
(white @62%, white@85% border), `brandGradient()` (BrandLight→BrandDark),
and `pressScale()` (120/180ms scale 0.95, observing a shared
MutableInteractionSource).

**Restyled primitives (ui/kit/Kit.kt)** — Btn: gradient pill, 52dp min
height, white 500-weight text, brand-tinted shadow, press-scale; secondary
= glass/white with Brand text. Card: the GlassCard treatment. Chip: active
= Brand50 tint with Brand text (per-tab tints preserved). Field/PickerField:
transparent boxes over the canvas with bottom hairlines (never the filled
M3 field). Avatar: gradient-initials Tile (12dp rounded, white letter, the
deterministic per-contact hue kept as a gradient). Toast: deep-ink glass
pill with hairline. Confirm: glass card, 28dp radius.

**Restyled shell (ui/CallmonyApp.kt)** — the root sits on glassCanvas();
the header is transparent over the glow canvas (logo + wordmark + gradient
search circle); the More sheet tiles are glass cards with press-scale; and
the bottom nav is the spec's floating solid-Brand bar: 28dp radius, 12dp
insets from the screen edges, white icons (inactive @80%), the center
dialer is a 68dp gradient FAB with a 4dp white ring and brand-dark shadow.
The nav's TOTAL height is pinned at exactly 71dp (64 bar + 7 inset) because
the v1.6.46/47 keypad-band contract (264dp keypad − 71dp nav = 193dp
reserved canvas band) measures the real nav — the first build used a
taller floating bar and the v1.6.43 band pin caught the 9dp regression
immediately.

**Hero numerals** — the General screen's net balance is now a 40sp Lexend
Light numeral in Brand (red when negative), with income/expense/open-lists
as soft-tinted pills beneath.

**Motion** — all new animations are 120-200ms terminating tweens
(press-scale, focus glow). The spec's optional pulsing FAB ring is
deliberately OMITTED: v1.6.51 just banished the app's last infinite
animation after the 101-second RenderThread ANR — the ANR lesson outranks
the decorative pulse (documented in the BottomNav comment).

## expect/actual & platform notes (spec delivery rule #5)

No new expect/actual — everything is commonMain Compose. The Haze
backdrop-blur library was NOT added (spec: only if real frosted glass is
requested; translucent white + hairline + glows is the standard look, with
the non-blur fallback always active). Platform differences: shadows render
slightly softer on iOS; radial-gradient glows are pixel-identical
everywhere (that's why blur was avoided).
