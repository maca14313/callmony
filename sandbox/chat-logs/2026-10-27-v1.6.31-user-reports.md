## Interpretation & resolution

1. **"the app won't open, it closes when i open it"** — a deterministic
   launch crash on the user's real device against v1.6.30. Investigation:
   the shipped release APK was downloaded from GitHub and verified
   byte-identical to the committed tree (all three DEX SHA-identical to a
   clean rebuild; only signing-block timestamps differ), the full Robolectric
   battery was green at that commit, and a NEW heavy harness
   (`V1631CrashReproTest`: real kv-seeded boot as a returning dark-theme
   Amharic user with 400 cached calls, 300 contacts and ledger balances,
   driving every v1.6.30 surface through the +4 s/+8 s boot effects) also
   passes — the crash lives in the JVM-vs-real-device gap. The structural
   fragility that fits the symptom: both store coroutine scopes had NO
   CoroutineExceptionHandler and every persistence/call-log guard caught
   `Exception` (not `Error` — OOM mid-decode on a 2 GB phone, a provider
   cursor Error), so ANY background-coroutine throwable at open = process
   death, and v1.6.30's no-splash first frame + hydrate's four concurrent
   decodes + the NEW ContentObserver's externally-triggered refresh all peak
   in the same window. Fixed belt-and-braces (exception handler on both
   scopes, Throwable-catch in hydrate/loadSystemCalls/fetchAll/loadSince,
   guarded observer callback + Runnable, observer registered after
   setContent). See CHANGELOG v1.6.31 for the full chain.

2. **"CONTACT DETAIL's history button should have some space between his
   neighbor, it should be at the start of the left side"** — the balance row
   was center-arranged with the history chip flush against the balance pill.
   Now `Arrangement.spacedBy(8.dp, Alignment.Start)`: left-anchored chip,
   fixed 8 dp gap to the pill.

3. **"need a ring colour on the inputs when they are active"** — new
   `Modifier.focusRing()`: a brand-coloured 2 dp ring fades in around any
   focused input box (all seven input surfaces) and out on blur; a pure
   observer that never requests or moves focus.

4. **"check github + apk + commit"** — GitHub checked (v1.6.30 was live with
   the APK asset; the asset hash matched the commit), v1.6.31 built and
   committed with the APK in `releases/`, pushed, released.
