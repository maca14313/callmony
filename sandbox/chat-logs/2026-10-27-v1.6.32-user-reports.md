## Interpretation & resolution

1. **"still the same it is not opening, go back 100% to v1.6.29 use it as a
   base continew from there and i think it is the splash screen thing is the
   problem"** — v1.6.31's exception-handler hardening did not stop the
   device crash, which invalidates the "Error escaping a catch(Exception)
   guard" theory as the primary cause and points at the v1.6.30 launch
   restructure itself: the splash was deleted (real shell composes from
   frame one) AND a call-log ContentObserver was added to MainActivity.onCreate
   — together they concentrate the whole launch peak (first-frame shell
   composition + hydrate's concurrent decodes + the boot call-log fetch +
   the observer's refresh) into one window on a low-RAM phone. The v1.6.29
   splash was structurally the launch safety buffer: frame one was a trivial
   pane and the real shell composed only after hydrate finished.
   RESOLUTION, exactly per the instruction: the working tree is reset to
   v1.6.29 (commit 2798e80) wholesale — splash pane + exit fade back,
   ContentObserver gone, Store/CallmonyApp/RecentsScreen/Calculator/SwipeRow/
   i18n byte-identical to v1.6.29 — and only the two pure-UI asks are ported
   back on top (they touch no launch path). Purity proof:
   `git diff 2798e80 -- composeApp/src` shows exactly 8 UI files + the
   version bump. Data safety verified: v1.6.30/31 added no persisted fields,
   and vc43 installs directly over the crashed vc42 with data intact.

2. **The ring colour + the history-button anchor (carried asks)** — ported
   verbatim from the v1.6.31 implementation (none of those 8 files were
   touched by the v1.6.30 launch rework, so the port is conflict-free):
   `Modifier.focusRing()` on all seven input surfaces (Field, entry-editor
   amount, dominant search, onboarding country search, contact-picker
   search, ledger quick item, keypad number display) and the contact-detail
   balance row `Arrangement.spacedBy(8.dp, Alignment.Start)` so the history
   chip anchors the left edge with a fixed 8dp gap to the balance pill.

## What was deliberately NOT re-applied

The rest of the v1.6.30 feature set — the full-number long-press strip, the
detail-page icon in the long-press sheet, calculator paste, the recents
owe/filter composing tabs + nav-button reset, the post-call ContentObserver
auto-refresh, and the flat-light call cards — rides the reverted launch-path
files and is therefore reverted with them. It can be re-added one-by-one on
this stable base, each with its own verification, once the app is confirmed
opening again on the device.
